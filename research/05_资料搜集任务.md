# RAGuard：你负责搜集的资料（按优先级）

## 第一批：最能提高代码与方法质量

1. Temporal 官方 Python samples 与幂等/重试文档：Activity 重试与外部幂等契约。
   https://github.com/temporalio/samples-python
   https://github.com/temporalio/documentation/blob/main/docs/develop/python/best-practices/error-handling.mdx
2. LangGraph checkpoint 和 durable execution：比较 Agent 恢复与外部 API 恢复的差别。
   https://github.com/langchain-ai/langgraph
   https://github.com/langchain-ai/langgraph/blob/main/libs/checkpoint/README.md
3. 官方 MCP Python SDK / tool annotations：研究 idempotentHint/readOnlyHint 在可信与不可信来源的不同意义。
   https://github.com/modelcontextprotocol/python-sdk
   https://blog.modelcontextprotocol.io/posts/2026-03-16-tool-annotations/
4. Shopify Toxiproxy：可注入网络故障；只用于沙箱。
   https://github.com/Shopify/toxiproxy

## 第二批：状态型工具任务数据

5. Sierra τ-bench / τ2-bench：真实任务结构与最终状态判定，优先抽取小规模文本任务。
   https://github.com/sierra-research/tau-bench
   https://github.com/sierra-research/tau2-bench
   注意 2026 年 10 月新版 τ-bench 2.0 与旧版指标不能直接对比。

## 搜集时每份至少填入

- 资料标题、原始 URL、许可证、版本或提交 SHA、发布时间；
- 功能简述、与本项目重合的核心机制、可直接运行的命令；
- 是否存在业务状态或真值、是否有重试/补偿/故障注入；
- 是否需要 API Key/GPU/外部服务、数据大小；
- 哪些部分不能直接复用或存在许可证限制。

## 不需要现在搜集

- 海量问答语料、通用预训练文本、私有付款日志、真实用户隐私数据；
- 不明确授权的付费 API 密钥或第三方服务凭据。

## 第三批：投稿查重必须对照的直接竞争论文

- DelAct（IWQoS 2026，已发表会议论文）：外部工具调用治理、未知提交验证、补偿。
  https://ieeexplore.ieee.org/abstract/document/11661202/
- LIMBO / Where Does Exactly-Once Live?（2026，预印本）：多故障条件、工具幂等契约与副作用账本。
  https://arxiv.org/abs/2609.29095
- Verified Tool Calls（2026，预印本）：verify-before-retry 和幂等键。
  https://arxiv.org/abs/2608.02645
- DART（2026，预印本）：依赖提交之后的语义可恢复性。
  https://arxiv.org/abs/2605.23311
- ACRFence（2026，预印本）：Agent 回滚后重新生成调用的重复副作用。
  https://arxiv.org/abs/2603.20625

重点不是直接复制这些论文的算法，而是获取源码、实验和实际假设，找到它们未解决、且我们能够验证的场景。
