# RAGuard · 投稿前景评估（2026-10-23）

## 结论

**研究方向值得做，但截至本次评审不能投 SCI。**

1. 当前 demo 主要是本地 HTTP + SQLite + Go 假工具，有合理的条件安全设计和真实并发测试。
2. 当前**零** B0–B5 研究对照数据，**零**跨领域/跨 Agent 泛化验证。
3. 核心机制重叠严重：DelAct (IWQoS 2026), Verified Tool Calls (2026), LIMBO (2026), Atomix, Cordon 和 DART。
4. 本项目最具潜力的是**明确异构外部服务的恢复准入边界 + 可信业务意图身份 + 有效期证据**，在强幂等基线下证明剩余的价值。

## 候选期刊及条件选择

| 期刊 | 适用前提 | 当前投稿判断 |
|---|---|---|
| Journal of Network and Computer Applications (JNCA) | 证明 API/网络故障契约、服务侧代价、规模/可靠性贡献 | 当前不建议，完善后可优先考虑 |
| Journal of Systems and Software (JSS) | 严谨软件工程方法、状态机、跨场景实验和复现包 | 当前不建议，走实证路线可考虑 |

## 推荐的三条出路

A（首选，需证伪）：安全恢复准入的系统性方法。若比 B3/B5 有收益且机制独立 → JNCA/JSS。

B（备选）：发现新的「证据时间窗口/异构契约」失效模式，作充分量化与复现 → JSS/IST。

C（若创新不足）：作为开源可靠性工具或毕业研究成果继续维护，但不强推同质化 SCI。

## 投稿前必须完成

- 区分现有方法和本方法的唯一贡献，一页 related-work gap matrix
- 项目内全部可测缺陷红绿测试、独立事实账本、一键评测
- 不能取巧弱化强幂等/回读基线
- 报出成功率、安全违约、人工升级、额外调用、时延及区间估计
- 配对种子和跨领域验证；明确 exactly-once 的不可能性与前提

**现阶段不应给出主观录用概率百分比**。先完成 G1/G2/G3，再决定目标期刊。
