### 本次审计可复现事实

- Python `python -m unittest discover -s tests -v`：17/17 PASS
- Go `cd mock && go test ./... -v`：2/2 PASS
- 第一轮修复后：同一可信业务引用即使改变 `step/intent`，也只产生 1 次物理效果；见 `tests/test_recovery_contract.py`。
- 第一轮修复后：已确认的可信回执在 TTL 内允许标记式回放，过期回执拒绝；这不等于保证外部现态不变。
- 非法调用/单机代次 CAS / 补偿保护已有一些用例，但不意味着形式证明或跨服务保证
- 运行平台为本次环境的 Linux + Python 3.13 + Go 1.23；**未做 Windows 真机验收**
