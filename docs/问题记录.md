## 必须维持的约束

- 只使用回环端口；日志不写密钥、请求体和个人资料。
- 不能把失败响应直接解释为外部服务未提交；不可为提高成功率而重试危险写操作。
- 当前只有本地模拟与部分对照实验，正式投稿需要跨领域强基线及充足样本。
- 源码、批处理和中文文档使用 UTF-8，注释解释关键逻辑，不添加冗长装饰性分隔线。

- Windows x64 随包 Go 沙箱是本地编译产物，运行前校验 SHA-256；如安全软件阻止执行，请保留提示和日志，不要直接关闭防护。
